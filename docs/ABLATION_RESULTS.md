## Experiment Design

| Setting | Value |
|---------|-------|
| Network size (N) | 300–5,000 nodes (calibrated benchmarks) |
| Graph type | Erdős–Rényi random graph ($G(N, p)$) |
| Seeds per config | Multi-seed independent runs (mean ± std) |
| Simulation steps | 20–50 OODA iterations per configuration |
| Churn | Disabled (confounds single-variable comparison) |
| Baseline | α = 2.0, β = 0.6, γ = 1.0, δ = 0.3 |

## Key Findings

1. **Proof-of-Throughput Impact (δ = 0.0 vs δ = 0.3 vs δ = 0.5):**
   * When δ is completely ablated ($\delta = 0.0$), average path length converges to 2.5335 (41.19% reduction) with a hub bandwidth of 54.77 Mbps and an incentive multiplier of 42.38×.
   * Introducing the Proof-of-Throughput term ($\delta = 0.3$) increases core hub bandwidth by **+21.7%** to 66.66 Mbps, elevates the bandwidth incentive multiplier to **50.22×**, and contracts APL down to 2.4835 (+42.35% reduction).
   * Increasing δ to 0.5 further tightens routing efficiency to 2.4727 APL (+42.67% reduction), validating that rewarding historical delivery throughput strictly stabilizes core-periphery hierarchies against free-riders.

2. **Optimal α Range (Centrality Incentive):**
   * Search query success rate reaches **50.0%** at $\alpha = 3.0$ with an average hop count of 2.51.
   * Setting $\alpha = 4.0$ creates excessive hub centralization pressure, causing degree saturation where search hops increase to 2.74 and success rate drops to 41.0%. The optimal regime for SCOPE is $\alpha \in [2.0, 3.0]$.

3. **Social Clustering & Triadic Closure (γ Sensitivity):**
   * Varying $\gamma$ from 0.2 to 2.0 maintains a robust clustering coefficient ($CC \approx 0.31 - 0.34$), reflecting organic emergence of cohesive peer cliques.
   * Search success rate climbs to **54.0%** at $\gamma = 2.0$, demonstrating that local clustering provides alternate redundant paths during greedy search routing.

4. **Connection Cost Balancing (β Sensitivity):**
   * Values of $\beta \in [0.1, 0.9]$ permit fluid rewiring toward high-centrality nodes while penalizing over-degree agents.
   * At $\beta = 1.2$, the aggressive maintenance cost suppresses edge additions, increasing APL to 2.5213 and search hops to 2.86. The baseline $\beta = 0.6$ provides the ideal equilibrium.
